## 章节结构

### 3.1 引言

- 生成式规划器（扩散 / 流匹配）在多模态轨迹建模上优于回归式；
- 但推理时从先验**随机采样一条**轨迹，同一模型同一场景会给出不同结果；
- 现有工作（GoalFlow、DiffusionDrive、MeanFuser）关注“怎么生成/怎么少步”，
  **没有研究“从分布里取哪个点”**；
- 本文主张：生成式规划器的性能损失有一部分来自**推断退化**，而非模型能力；
- 贡献三点：① 量化单样本推断的方差；② 提出中心推断（零噪声 / medoid）；
  ③ 中心一致性训练，使分布中心本身成为好解；（可选 ④ 更强视觉基座）。

### 3.2 单样本推断的问题

**形式化。** 生成器学习条件分布 $p(\xi \mid c)$，推理时采样
$\xi \sim p(\cdot \mid c)$，评测 $S(\xi)$。评测指标对采样敏感：
$\mathbb{E}[S(\xi)]$ 与 $S(\mathbb{E}[\xi])$ 不相等，且 $\mathrm{Var}[S(\xi)]$ 可能很大。

**三个来源。**
1. 先验噪声：ODE 起点不同，积分结果不同；
2. 多模态：分布有多个峰，单样本落在哪个峰是随机的；
3. 训练-推理不一致：训练时看到的是真值插值点，推理时是模型自己的积分轨迹。

**实证设计。**
- 同一 checkpoint、同一 navtest、固定其余条件，重复评测 $N$ 次；
- 报告分数的均值、标准差、分位数；
- 对比“单样本”与“100 条的中心”。

### 3.3 确定性推断

**3.3.1 零噪声确定性路径。**
令 ODE 起点 $x_0 = 0$（先验均值），得到一条确定性路径。优点是零额外开销、完全可复现；
但**它一般不等于条件均值或众数**，若分布多模态可能落在峰之间——是否优于随机样本是待验证假设。

**3.3.2 medoid 中心样本。**
采样 $K$ 条，取到其余样本距离和最小者：
$$\xi^\star = \arg\min_{i} \sum_{j} d(\xi_i, \xi_j).$$
medoid 落在最大模态的中心，抗多模态；代价是 $K$ 次前向。注意它不是逐时刻坐标中位数。

**3.3.3 选择准则。**
若分布近似单峰，零噪声路径即可；若多峰，用 medoid。
给出判别方式（样本间距离分布 / 模态数估计）。

### 3.4 中心一致性训练

中心推断只在推理时补救；若能让**中心本身就是好解**，收益更稳。

- 对零噪声路径的还原轨迹 $\hat{\xi}_0$ 施加与主损失同口径的辅助监督
  （归一化增量空间的漂移 + 航向）；
- 权重与主损失同量纲（除以 $t_\mathrm{eff}$），避免量级失控；
- 与流匹配主损失互补：主损失管“每条样本”，中心损失管“分布中心”。

### 3.5 更强的视觉基座（可选，保底）

- 当前 DP 的 BEV 骨干为 VoV-99；
- 接入 Depth Anything ViT-L（权重已有）：对齐特征维度、锚点池化与 BEV 融合层；
- 目的：在方法增益不足时，用感知能力把绝对分数抬上去。

### 3.6 讨论与局限

- 中心推断不改变模型参数，推理开销可调（$K$ 次前向）；
- medoid 在极端多模态场景下仍可能选错模态；
- 单种子评测的方差需要多种子报告。

### 3.7 本章小结

## 与现有工作的区别

| 工作 | 关注点 | 本文差异 |
|---|---|---|
| GoalFlow | 目标点 + 单步 FM | 不改生成框架，改“取哪个点” |
| DiffusionDrive | 锚点 + 截断扩散 | 无锚点、无评分器 |
| MeanFuser | 一步生成 + 自适应重建 | 不追求一步，追求分布中心 |
| FlowR2A | 奖励条件生成 | 不依赖仿真奖励 |
